# Integrations

HFIOR is platform-neutral; integrations bind its roles to a concrete input and
authorization stack.

| Integration | Status |
| --- | --- |
| [Hyprland + Aquamarine](hyprland/README.md) | First experimental native reference target |
| [Aquamarine](aquamarine/README.md) | Timestamp and observation backend |
| [Experimental Wayland protocol](wayland/README.md) | Unstable design, not official |
| [Linux producer](linux/README.md) | Existing userspace bridge; kernel work conditional |

No page implies upstream endorsement or acceptance.
