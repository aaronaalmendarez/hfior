# Roadmap

## 0.x: Research and experimental ABI

- Reproduce with a second 8 kHz mouse and a second physical machine.
- Measure motion-to-photon latency with external optical hardware.
- Produce a reviewable Hyprland/Aquamarine native prototype and patch series.
- Refine protocol authorization, lifecycle, clock, and extension semantics.

## Later, evidence permitting

- Reproduce the authorized history path in another Wayland compositor.
- Consider a kernel producer only if profiling finds material avoidable cost
  below the compositor/userspace boundary.
- Prepare upstream proposals only after independent reproduction and security
  review.

Dates and upstream acceptance are intentionally not promised.
