# Raw evidence

`controlled-late-latch/` contains the compact joined synthetic trace retained for
public audit. Each policy directory includes the exact run environment, bridge
and client summaries, frame/record/publication traces, integrity result, system
counters, and a SHA-256 manifest.

`physical-game-8k/` contains the final trajectory-preserving game campaign:
five accepted eager runs, five accepted HFIOR runs, raw per-frame CSV files,
per-run summaries, and the aggregate result.
